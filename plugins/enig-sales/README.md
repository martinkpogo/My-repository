# enig-sales plugin

Foundation package. Version 0.1.0 (no prior baseline in repository). Contains the skills `sales-call-prep` and `sales-call-evidence`; the remaining sales skills are tracked by later issues.

## Packaging
Zip the plugin directory (contents at root) as enig-sales.plugin.

## Validation
- Manifest valid JSON with required fields.
- SKILL.md present.
- Structural checks via scripts/validate_plugin.py.
